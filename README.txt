筋トレ日誌 PWA v3.1

変更点
- 筋力トレーニングと有酸素運動を種目ごとに切り替え可能。有酸素は複数区間と区間後レストを記録できます。
- 種目全体の「改善点・原因・対策」を追加しました。
- 同種目の過去履歴から、空欄のメイン部位・サブ部位を自動入力します。
- 自己ベストを「重量＋同重量内のセット順」で判定します。
- アップを青、本番をオレンジ、補充セットを緑で強調表示します。
- 「この日を複製」後の日付変更で、複製内容を維持したまま別の日へ移せます。
- 無効な時刻は入力欄を離れたときに削除します。
- TXTバックアップをVersion 8へ更新し、Version 6・7も引き続き取り込めます。
- データ管理欄を画面最下部、「＋種目を追加」カードの直下へ移動。
- 「全記録を削除」は、最新状態の一括バックアップを確認済みで、そのバックアップから10日以内の場合のみ実行可能。
- 一括バックアップ履歴がない、または10日以上経過している場合は、
  「全記録を削除できません。一括データ出力でバックアップを取ってください」
  と表示し、削除処理へ進みません。
- 10日以内の場合のみ、最終バックアップ日時を表示した確認画面を出します。
- 一括バックアップ後に記録を変更した場合は、再度一括出力するまで全削除できません。
- 旧localStorageデータのIndexedDB移行は一度だけ実行し、削除後に旧記録が復活しないようにしています。
